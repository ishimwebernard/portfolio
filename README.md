## Bernard Ishimwe — Portfolio (Next.js + Tailwind)

Professional single-page portfolio built with Next.js (App Router) and Tailwind CSS.

### Edit content

All CV content is centralized in:

- `src/data/cv.ts`

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

### Build

```bash
npm run build
```

### Notes

- Update your GitHub/LinkedIn URLs in `src/data/cv.ts` (they’re placeholders by default).
